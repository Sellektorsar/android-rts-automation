# Recovery and Safety
Stop on ADB disconnect, locked device, unknown dialog, login/security/CAPTCHA, payment, low confidence, unexpected orientation or two consecutive unverified actions. Take a fresh screenshot, inspect the last confirmed state and report what is known/unknown. Close only an unambiguous harmless popup if policy allows. Do not bypass anti-cheat, CAPTCHA, access controls or account protections. No blind retries, infinite loops, purchases, premium spending, rare-item use, player PvP, teleportation, alliance changes or messaging without explicit owner approval. Report last confirmed goal, last action, reason for stopping and safest next step.
