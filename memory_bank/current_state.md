## ✅ Что работает

- Подключение, mDNS-поиск, скан портов, переподключение, перезапуск ADB.
- Pull-захват кадра (~1.8–1.9 с), кэш кадра, `frame_age()`.
- **Быстрый поток `FastCapture`**: `adb exec-out screenrecord --output-format=h264`
  → `ffmpeg` → BGR `540×1218`; живой замер **14.11 FPS** (30 кадров за 2.126 с),
  в статичном диалоге/бою — до **~44 FPS** (682 кадра за 15.2 с).
- Классификация экранов по якорям + OCR-резерв:
  `city_view`, `royal_road`, `alliance_menu`, `quests_menu`,
  `building_menu`, `building_upgrade`, `popup_offer`, `popup_generic`,
  `loading`, **`tutorial_battle`** (боевой экран).
- **Боевой экран**: якорь `battle_pause` `(62, 150)`; для быстрых кадров
  `540×1218` — отдельный `battle_pause_fast`.
- **Безопасный вход/выход из боя этапа 7**: брифинг → «Испытание» →
  диалог героизма (только зелёная кнопка) → бой → пауза → «Выйти» →
  карта кампании → город. Выход не открывает оплату и не требует
  подтверждения.
- HUD: энергия, еда, дерево, сила, золото, самоцветы, VIP.
- Безопасная навигация: возврат в город, штатная стрелка, диалог выхода.
- `ActionGuard`: свежесть, тёмный кадр, пересъёмка, ожидание шаблонов,
  стабильность, изменение области, подтверждение действия.
- Адаптивный backoff задач по истории сбоев.
- WorldModel: строители, таймеры, ближайшее событие, summary, кампания
  (глава/этап/брифинг) и `update_campaign()`.
- CityHarvest (grain/wood) и CityGifts (подарок торговца).
- QuestRewards: открывает ежедневные задания, нажимает **только** зелёную
  «Забрать награды», возвращается в город; премиальные кнопки не трогает.
- BuildingUpgrade: полный flow улучшения, OCR названия/уровней/таймера,
  запись подтверждённого таймера в WorldModel.
- Вход в Королевскую Дорогу по OCR-баннеру + иконке короны `(75, 1960)`;
  экран `royal_road` классифицируется якорем `title_royal_road` (1.00).
- `tools/probe_royal_road.py` — безопасный зонд: открывает экран, читает
  главу/кнопки, сохраняет кадр и возвращается по `Back`, не начиная бой.
- Вход на карту кампании через портал `(522, 1230)`; экран `campaign_map`
  классифицируется якорем `title_campaign` (1.00).
- Этап 7: брифинг `stage_briefing` с целью «Выжить в течение 120 сек.»,
  навык «Удар дракона», кнопка «Испытание» `(540, 1875)`. Флаг бывает
  ярко-синим `(955, 1200)` и тёмно-синим `(943, 1416)`, когда карта
  затемнена диалогом босса; поддерживаются оба шаблона.
- `tools/probe_stage7_combat.py` — контролируемый вход в бой и безопасный
  выход; без `--confirm` бой не начинается, `--dry-run` только открывает
  брифинг.
- Экран `quests_menu` (ежедневные задания) классифицируется якорем
  `title_daily_quests` (`0.989`), а не как `popup_reward`; вход — нижняя
  кнопка «Задание» `(290, 2370)`, `Back` возвращает в город.

## 🚧 Блокеры и ограничения

- Стена Замка уже `LV.5` при замке `LV.5`; следующий уровень может требовать
  более высокого замка/лорда. Для живой проверки `BuildingUpgrade` нужно
  найти другое доступное здание.
- Нижний баннер города показывает **«Вызов Спасителя порядка, этап 7 (0/1)»**;
  экран Королевской Дороги подтвердил главу **4 «Вербовка Войск I»**.
  `current_chapter=4` корректно, `current_chapter_title` заполнен.
- «Вперёд» этапа 7 закрывает окно и возвращает в город; вход на карту —
  через основание портала. Боевой цикл этапа 7 подтверждён отдельным
  зондом `probe_stage7_combat.py --confirm`.
- Боевой автопилот не реализован: есть только распознавание боя и
  безопасный вход/выход. Управление джойстиком, выбор навыков,
  победа/поражение и повтор этапа — следующие задачи.
- `FastCapture` ещё не интегрирован в `BotEngine`; при мгновенном выходе
  из боя поток не успевает дать боевые кадры, а детекция срабатывает по
  полному кадру (`pull_fallback`). Для реального боя нужен прогрев потока
  до нажатия «Испытание» и автоперезапуск после `--time-limit`.
- Аккаунт не в альянсе — альянс-задачи отключены.
- Нет шаблонов `bubble_stone`, `bubble_iron`, `bubble_wishing_well`.
- `android-harness` daemon на Unix-socket не подходит для Windows.
- `esp32-android-agent` HID-часть требует аппаратного ESP32.
- `tools/run_campaign_via_road.py` — старая заготовка, не входит в коммит;
  использует жёсткие координаты, перед включением требует ревизии.

## 🎯 Активная разработка (P0)

1. **Пересъёмка устаревшего кадра** — реализовано:
   `ActionGuard.refresh_if_stale()`, `BaseTask.ensure_screen()`;
   используется в `BuildingUpgradeTask` и `CityGiftsTask`.
2. **Таймер улучшения → WorldModel** — реализовано:
   OCR области таймера, `parse_duration()`, `world.start_upgrade(...,
   current_level=...)`, запись только после исчезновения панели.
3. **Живая проверка** — следующее: найти доступное здание, включить
   `building_upgrade`, проверить, что таймер появился в `world_model.json`.
4. **Soak 10–15 минут** с `keep_screen_on` и без потери ADB.
5. **Кампания (P1)** — вход в Королевскую Дорогу, карту кампании и
   брифинг подтверждён; боевой экран классифицирован, безопасный
   вход/выход этапа 7 проверен вживую.
6. **Бой (P2)** — следующий шаг: прогреть `FastCapture`, дождаться
   боевого кадра, реализовать джойстик/выбор навыков и обработку
   победы/поражения. Не нажимать «Повторить», «Купить» и золотой молот.

## 📏 Правила

- Не кликать вслепую по координатам: только по шаблону или уверенному OCR.
- В бою выходить только по шаблону `btn_battle_exit`; OCR путает
  «Выжить в течение…» с «Выйти».
- В диалоге героизма нажимать только зелёное «Испытание»; синее
  «Укрепление героизма» не трогать.
- Не нажимать зелёную кнопку гемов и любые кнопки оплаты.
- Не подтверждать «Выйти из игры?».
- Не коммитить `logs/` и скриншоты с данными аккаунта.
- После нового экрана — карточка в `screens_manifest.md` и координаты в
  `ui_coordinates.yaml`.
- После изменения поведения — запись в `development_log.md`.
