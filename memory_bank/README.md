# Банк памяти (Memory Bank) — War & Order Bot

Банк памяти — это структурированное хранилище знаний об устройстве пользовательского интерфейса, экранах, координатах, переходах и сценариях игры *War & Order*.

## 📁 Содержимое банка памяти

1. **`screens_manifest.md`**:
   - Полный каталог всех обнаруженных состояний игры (FSM State Graph).
   - Визуальные ориентиры, якорные цвета, расположение ключевых кнопок и логика переходов.
   
2. **`ui_coordinates.yaml`**:
   - Машиночитаемые координаты и зоны интереса для разрешения 1080x2436.
   - Используется задачами (`tasks/`) для быстрого позиционирования, резервных кликов и кадрирования шаблонов.

3. **`dialogs_and_lore.md`**:
   - История сюжетных диалогов, персонажи (Белла, Огненный демон и т.д.), отслеживание заданий кампании и условий открытия функционала.

## 🔄 Правило обновления банка памяти

При обнаружении каждого нового экрана:
1. Делается скриншот и сохраняется в `assets/screens/<screen_id>.png` или исследуется.
2. В `screens_manifest.md` добавляется карточка нового состояния:
   - ID состояния
   - Скриншот-референс
   - Интерактивные элементы
   - Правила входа и выхода
3. Новые координаты добавляются в `ui_coordinates.yaml`.
4. Новые шаблоны кнопок сохраняются в `assets/`.
