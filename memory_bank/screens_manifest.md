Разрешение экрана устройства: **1080 x 2436** (вертикальная ориентация, Tecno CL8).

## 📸 Подробный каталог экранов

### 1. Экран начального боя (Tutorial Battle)
- **ID состояния**: `STATE_TUTORIAL_BATTLE`
- **Описание**: Герой на арене, окруженный скелетами. Управление движением через виртуальный джойстик в нижней половине экрана.
- **Ключевые элементы**:
  - Джойстик: центр `(x ~ 540, y ~ 1800)`.
  - Полоса здоровья героя: вверху по центру `(y ~ 120-180)`.
  - Пауза / Настройки: верхний правый угол.
- **Действие для перехода**: Зажать джойстик и подвести героя к монстрам, автоатака уничтожает врагов.

---

### 2. Экран выбора улучшения / навыка (Skill Selection Modal)
- **ID состояния**: `STATE_SKILL_SELECTION`
- **Описание**: Модальное окно с тремя картами улучшений («Вызвать Жар-птицу», усиление атаки, щит).
- **Ключевые элементы**:
  - Первая карта навыка (Жар-птица): центр `(x ~ 540, y ~ 750)`.
  - Зеленая кнопка подтверждения выбора: `(x ~ 540, y ~ 1400)`.
  - Шаблон кнопки: `assets/btn_green_confirm.png`.
- **Действие для перехода**: Клик по карте, затем клик по зеленой кнопке подтверждения.

---

### 3. Экран диалога с сюжетными персонажами (Story Dialogue)
- **ID состояния**: `STATE_STORY_DIALOGUE`
- **Описание**: Полноростовой персонаж (Белла, советник, враг) на фоне карты с диалоговой плашкой в нижней части экрана.
- **Ключевые элементы**:
  - Портрет/модель персонажа: центр экрана `(y ~ 1000 - 1800)`.
  - Диалоговая рамка (свиток): от `y = 2050` до `y = 2436`.
  - Имя говорящего (коричневая плашка): `(x ~ 540, y ~ 2100)`. Пример: «Белла».
  - Текст реплики: `(x ~ 150 - 900, y ~ 2150 - 2350)`.
  - Мигающий индикатор продолжения (стрелка вниз): `(x ~ 940, y ~ 2380)`.
- **Действие для перехода**: Одиночный клик в область диалоговой рамки `(x ~ 540, y ~ 2250)` для перелистывания реплик.

---

### 4. Карта кампании: "Спаситель порядка" (Campaign Map)
- **ID состояния**: `STATE_CAMPAIGN_MAP`
- **Описание**: Вертикальная тропа с узловыми точками уровней (1..10), ведущая к боссу «Огненный демон». В режиме обучения заблокирован свободный выход, горит золотая анимированная рука-указатель на Уровень 1.
- **Ключевые элементы**:
  - Заголовок вверху: «Спаситель порядка» `(x ~ 540, y ~ 55)`.
  - Кнопка «Назад» (золотая стрелка влево): `(x ~ 60, y ~ 55)`. *Примечание: во время обязательного туториала может быть заблокирована.*
  - Уровень 1 (Синий флаг с цифрой 1 в золотом кольце): центр `(x = 730, y = 2070)`.
  - Золотая рука-указатель обучения: указывает на Уровень 1 с координат `(x ~ 850, y ~ 2000)`.
  - Переключатель сложности: «Простой» `(x ~ 800, y ~ 130)`, «Трудный» `(x ~ 920, y ~ 130)`.
  - Огненный демон (Босс): `(x ~ 540, y ~ 650)`.
- **Действие для перехода**: Клик по Уровню 1 `(x = 730, y = 2070)` для запуска этапа.

---

### 5. Окно запуска этапа кампании (Stage Briefing / Challenge Modal)
- **ID состояния**: `STATE_STAGE_BRIEFING`
- **Описание**: Модальная карточка подготовки к битве с описанием этапа (например, «Этап 1: Убить всех монстров», «Этап 2: Штормовой меч») и списком первых наград (ускорители 5 мин, пища 1.0K, дерево 1.0K).
- **Ключевые элементы**:
  - Картинка осажденной крепости: верхняя часть карточки `(y ~ 600 - 900)`.
  - Название этапа: «Этап 1 / 2» `(x ~ 540, y ~ 950)`.
  - Цель: «Убить всех монстров» `(x ~ 540, y ~ 1010)`.
  - Иконка нового навыка этапа: `(x ~ 365, y ~ 1115)`.
  - Награды: слоты `(x ~ 280, 500, 720; y ~ 1340)`.
  - Зеленая кнопка **«Испытание»** (Start Battle): центр `(x = 500, y = 1770)`.
- **Действие для перехода**: Клик по кнопке «Испытание» `(x ~ 500, y ~ 1770)`.

---

### 5.1. Экран победы этапа (Stage Victory / Completion Screen)
- **ID состояния**: `STATE_VICTORY_SCREEN`
- **Описание**: Экран триумфа после уничтожения 100% монстров этапа. По центру герб с золотой короной и лентой «Задание выполнено», список полученных трофеев.
- **Скриншот**: `assets/screens/stage_1_victory.png`
- **Ключевые элементы**:
  - Надпись «Задание выполнено»: `(x ~ 540, y ~ 900)`.
  - «Поздравляем с победой!»: `(x ~ 540, y ~ 1090)`.
  - Иконки наград (5 min ускорение, 1.0K зерно, 1.0K дерево): `(y ~ 1240)`.
  - Подсказка «Нажмите в любом месте, чтобы продолжить»: `(x ~ 540, y ~ 1850)`.
- **Действие для перехода**: Клик в любую свободную область экрана, например `(x = 540, y = 1850)`.

### 6. Основной экран Замка / Города (City View) — [Подтверждено и Зафиксировано]

- **Скриншот**: `current_screen.png`
- **Ключевые элементы**:

    - Аватар Лорда: центр `(x = 90, y = 192)`, уровень 1.
    - Энергия / Дух Лорда: иконка `(x = 180, y = 120)`, значение `100` `(x = 240, y = 120)`.
    - Зерно (Пища): иконка `(x = 345, y = 120)`, значение `100.0K` `(x = 415, y = 120)`.
    - Дерево: иконка `(x = 515, y = 120)`, значение `100.0K` `(x = 580, y = 120)`.
  - **Верхняя панель (HUD - Второй ряд)**:
    - Боевая мощь: иконка скрещенных мечей `(x = 225, y = 185)`, значение `3,091` `(x = 285, y = 185)`.
    - VIP-статус: лента `VIP1` `(x = 240, y = 240)`.
    - Золотые монеты: `(x = 815, y = 185)` (баланс: 0).
    - Самоцветы (Алмазы): `(x = 1010, y = 185)` (баланс: 100).
  - **Левая панель быстрого доступа**:
    - Слот строителя (Спящий молот `Z`): центр `(x = 75, y = 402)`, шаблон `assets/templates/btn_builder_idle.png`.

  - **Нижняя панель навигации** (`y ~ 2270 - 2436`):
    - Переключатель «Карта Королевства / Город» (Золотой дракон с глобусом): центр `(x = 115, y = 2355)`.
    - «Задание» (Свиток с пером): центр `(x = 295, y = 2375)`.
    - «Рюкзак» (Кожаная сумка): центр `(x = 455, y = 2375)`.
    - «Почта» (Письма с сургучом): центр `(x = 615, y = 2375)`.

    - «О Лорде» (Король в доспехах): центр `(x = 930, y = 2375)`.

### 7. Всплывающее рекламное окно / Акция (Popup Promo / Notice) — [Ожидается]
- **ID состояния**: `STATE_POPUP`
- **Описание**: Всплывающий баннер с акциями («Первая покупка», «Набор новичка», «Событие»).
- **Ключевые элементы**:
  - Кнопка закрытия (Крестик `X`): обычно в правом верхнем углу модального окна `(x ~ 900 - 1000, y ~ 200 - 500)` либо в левом верхнем углу.
- **Действие для перехода**: Клик по крестику или нажатие аппаратной кнопки `Back` (keyevent 4).
