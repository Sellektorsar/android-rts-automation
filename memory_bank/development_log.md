## 2026-10-22 — Стабилизация 2.0: guard refresh + таймер улучшения

### Сделано

- `src/action_guard.py`:
  - добавлен `refresh_if_stale()`: при устаревшем/тёмном кадре делается один
    свежий снимок; если и он непригоден — действие отменяется.
- `src/tasks/base_task.py`:
  - добавлен `ensure_screen()`, который использует `refresh_if_stale()`.

  - перед действием вызывается `ensure_screen()` вместо жёсткой отмены.

  - `ensure_screen()` перед действием;
  - OCR названия здания, уровней `LV.N → LV.M` и таймера над синей кнопкой;

  - поддержка трёх форматов `spots` (точка, dict с `name`/`point`, пара);
  - защита от занятых строителей по world model.
- `src/time_parser.py`:
  - разбор `11:52`, `1:02:03`, `11.52`, `11 мин 52 сек`, `1 ч 2 мин 3 с`,
    `1152`; отказ при невозможных значениях.
- `src/world_model.py`:
  - `start_upgrade(..., current_level=...)` — уровень с панели авторитетен;
  - в состояние по умолчанию добавлена стена.
- `src/bot_engine.py`:
  - `BuildingUpgradeTask` получает `world=self.world`.
- `config.yaml`:
  - точка стены переведена в формат `name` + `point`.
- Банк памяти:
  - `current_state.md`, `decisions.md`, `dialogs_and_lore.md`, этот журнал;
  - обновлены `screens_manifest.md`, `ui_coordinates.yaml`, `world_model.json`.
