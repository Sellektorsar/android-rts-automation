# Сторонние проекты и заимствованные идеи

WaO_bot использует идеи и небольшие адаптированные фрагменты из проектов
с лицензией MIT. Полные тексты лицензий доступны в исходных репозиториях.

| Проект | Автор/репозиторий | Лицензия | Что использовано |
|---|---|---|---|
| Android Harness | https://github.com/yang1ming/android-harness | MIT | Идеи проверки снимков, редактирования чувствительных данных и политик безопасности |
| ESP32 Android Agent | https://github.com/shenlan-ai/esp32-android-agent | MIT | Свежесть кадра, проверка тёмного кадра, стабильность экрана, подтверждение действия, нормализованные координаты |
| 4X Game Agent | https://github.com/sonpiaz/4x-game-agent | MIT | World model и таймеры, reflection-журнал, FSM со стеком попапов, адаптивные координаты зданий |

Если в будущем фрагменты кода будут скопированы дословно, необходимо
сохранить уведомление об авторских правах и текст MIT-лицензии из
соответствующего репозитория.

Подробный разбор: [`repo_analysis.md`](repo_analysis.md).
