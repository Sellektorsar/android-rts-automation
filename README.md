# War and Order (WaO) Bot 🏰🤖

Продвинутый модульный бот для автоматизации игры **War and Order** на Android-устройствах через ADB (Wi-Fi / USB).

---

## 🌟 Ключевые возможности

- 🎮 **Интеллектуальный боевой движок (Кампания / Спаситель порядка):**
  - Траектория движения *"Figure-8 Vacuum Kite"* — непрерывный сбор 100% кристаллов опыта (EXP gems) через пересечение центра джойстика.
  - Умный выбор карт способностей при повышении уровня (Магнит/Радиус сбора > Алхимическая пушка > Божественный щит > Штормовой меч > Разряд).
  - Автоматическое определение победы, поражения (с автоповтором) и сбор трофеев.

- 🏗️ **Автоматизация развития города:**
  - Улучшение Замка, Казарм, Колледжа и стен.
  - Распознавание радиального меню построек и модальных окон.
  - Автоматическое применение бесплатных мгновенных ускорений (`Free Speedup`).
  - Вербовка и тренировка войск.

- 📜 **Автоматическое прохождение глав (Королевская Дорога):**
  - Модульные конвейеры глав (Главы 1, 2, 3, 4+).
  - Сбор наград с баннера HUD и финальных наград главы.
  - Автоматический переход к следующим этапам.

- 🛡️ **Anti-Detection & Human-Like Input:**
  - Гауссовское случайное смещение кликов (Jitter radius).
  - Плавные свайпы по кривым Безье.
  - Человекоподобные случайные задержки между действиями.
  - Автоматическое сворачивание шторки уведомлений Android.

- 👁️ **Компьютерное зрение и OCR:**
  - Локальный OCR через `RapidOCR` (ONNX Runtime, без облачных API).
  - Шаблонное сопоставление `OpenCV` с адаптивными порогами.
  - Сегментация интерфейсных элементов в цветовом пространстве HSV.

## 🚀 Быстрый старт

### 1. Установка зависимостей
Требуется Python 3.10+:
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Подключение устройства
Включите режим разработчика и отладку по USB/Wi-Fi на телефоне.
Укажите параметры в `config.yaml`:
```yaml
device:
  adb_path: "adb"
  ip: "192.168.31.156"
  port: 33565
  timeout_sec: 10
```

### 3. Запуск скриптов
- Прохождение боевого этапа кампании:
  ```bash
  python tools/run_stage6_master.py
  ```
- Улучшение зданий:
  ```bash
  python tools/upgrade_barracks_to_lv4.py
  python tools/upgrade_college_to_lv4.py
  ```
- Автоматический сбор наград и продвижение по квестам:
  ```bash
  python tools/complete_chapter_quest.py
  ```
