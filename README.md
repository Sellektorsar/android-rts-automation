## 🌟 Ключевые возможности

- 👁️ **Компьютерное зрение и локальный OCR:**
  - Локальное распознавание текста через `RapidOCR` (ONNX Runtime, без облачных API и задержек сети).
  - Шаблонное сопоставление `OpenCV` (Template Matching) с настраиваемыми коэффициентами сходства.
  - Сегментация интерфейсных элементов в цветовом пространстве HSV (поиск активных кнопок, маркёров, иконок).

- 🎮 **Интеллектуальный боевой движок для RTS-сражений:**
  - Траектория движения *"Figure-8 Vacuum Kite"* — непрерывный сбор ресурсов и кристаллов опыта (EXP gems) с динамическим пересечением центра джойстика.
  - Алгоритмический выбор карт способностей при повышении уровня (Магнит/Радиус сбора > АОЕ-урон > Защитные барьеры > Направленный урон).
  - Автоматическое распознавание окончания битвы (победа, сбор лута, автоповтор при неудаче).

- 🏗️ **Управление инфраструктурой и развитием базы:**
  - Распознавание радиальных меню построек и модальных окон улучшений.
  - Определение доступности мгновенных бесплатных ускорений (`Free Speedup`).
  - Вербовка и планирование очереди тренировки отрядов.

- 📜 **Автоматизация конвейеров заданий (Campaign & Quest Flow):**
  - Модульные конвейеры прохождения сюжетных этапов и глав.
  - Автоматическое получение наград на HUD и в журнале заданий.
  - Навигация между картой города и картой экспедиций.

- 🛡️ **Защита от обнаружения и реалистичный ввод (Human-Like Input):**
  - Гауссовское случайное смещение кликов от центра кнопки (Click Jitter).
  - Плавные свайпы по кривым Безье переменной скорости.
  - Псевдослучайные задержки между микро-действиями.
  - Автоматическое управление системными панелями Android.

## 🚀 Быстрый старт

### 1. Установка зависимостей
Требуется Python 3.10+:
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Подключение устройства
Включите режим разработчика и отладку по USB или Wi-Fi на Android-устройстве.
Настройте параметры в `config.yaml`:
```yaml
device:
  adb_path: "adb"
  ip: "192.168.31.156"
  port: 33565
  timeout_sec: 10
```

### 3. Запуск модулей
- Запуск автономного прохождения боевого этапа:
  ```bash
  python tools/run_stage6_master.py
  ```
- Автоматизация прокачки инфраструктуры:
  ```bash
  python tools/upgrade_barracks_to_lv4.py
  python tools/upgrade_college_to_lv4.py
  ```
- Выполнение заданий и сбор наград:
  ```bash
  python tools/complete_chapter_quest.py
  ```
